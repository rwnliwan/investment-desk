# Investment Desk — Putuskan seperti pemilik bisnis

**Thesis. Valuasi. Kesabaran.**

Kursus dan simulator keputusan investasi: membangun thesis, menilai valuasi, dan memutuskan beli/tahan/lepas — dari sudut pandang pemilik bisnis.

**Live:** https://investment-desk.pages.dev/

## Isi

- **I1–I4** — fondasi analisis investasi (thesis, valuasi, margin of safety, kesabaran)
- **Investment Committee Simulator** (flagship) — 3 emiten fiktif: BUY / HOLD / PASS

## Teknologi

Static site — HTML/CSS/JS murni, deploy via Cloudflare Pages. Progres tersimpan di localStorage.
